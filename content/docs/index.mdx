## What this is

A complete **2-week ASP.NET Core Web API mastery program**, built for a staff-level
engineer: dense, senior-level depth, no beginner filler, and scenario-based
interview questions that mirror real debugging conversations.

- **12 chapters**, ~3–4 focused hours per day, with days 7 and 14 as buffer + mock interview.
- **One project** — [CommerceHub](https://github.com/ahadkhan9/aspnet-mastery) —
  an order & inventory e-commerce backend that every chapter builds on.
- **Every chapter** ends with interview Q&A, root-cause scenarios, and a concrete
  project task with acceptance criteria.

## How to use it

Give a chapter name + index, and the improved prompt (in the plan) produces the
next chapter in the same consistent structure. Chapters land in
`content/docs/chapters/` as they're written.
